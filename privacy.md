# Privacy Policy

Last updated: 14 November 2026

AI YouTuber Agent ("the app") is a private desktop tool used only by its owner to manage the owner's own YouTube channels.

## What data the app accesses

When the owner signs in with Google, the app receives access to the owner's YouTube account through the YouTube API Services, limited to:

- the owner's channel information, videos, playlists, captions and comments
- the owner's YouTube Analytics reports for those channels

## How the data is used

The data is used only to provide the app's features to the owner: uploading and updating the owner's videos, setting thumbnails, captions and playlists, replying to comments on the owner's channels, updating the channel's branding, and reading the owner's own analytics to plan better videos.

## How the data is stored

Sign-in tokens and analytics are stored only on the owner's own computer. They are not sent to any server run by the app; there is no such server.

## Sharing

The data is never sold, shared with, or transferred to anyone else, and it is not used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements: https://developers.google.com/terms/api-services-user-data-policy

## YouTube and Google

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service: https://www.youtube.com/t/terms

Google Privacy Policy: https://policies.google.com/privacy

## Removing access

Access can be revoked at any time at https://myaccount.google.com/permissions or through the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the app's local data folder removes everything it stored.
