# AI YouTuber Agent

AI YouTuber Agent is a private desktop tool. Its owner uses it on their own computer to produce videos and publish them to the owner's own YouTube channels. It is not offered to, sold to, or used by anyone else.

## What it does with YouTube

With the channel owner's permission (Google sign-in), it uses the YouTube Data API to:

- upload the owner's videos and set their titles, descriptions, tags, thumbnails, captions and playlists
- read the owner's own channel and video statistics (YouTube Analytics) to improve future videos
- read and reply to comments on the owner's own channels
- update the owner's channel description, keywords and banner
